# ESP8266 Code

Dokumentation für die ESP-Firmware liegt zentral im Repository `DarkNinja-Lab/DynoraStation` auf `main`.

- Hardware- und Anschlussdetails: `../docs/HARDWARE.md`
- MCP23017-Anschluss: `./MCP23017_ANSCHLUSS.md`
- Vorkonfigurierte Relais-/Sensorvarianten: `relays_und_sensoren_8r_1mcp.ino`, `relays_und_sensoren_16r_1mcp.ino`, `relays_und_sensoren_16r_2mcp.ino`, `relays_und_sensoren_24r_2mcp.ino` und `relays_und_sensoren_32r_2mcp.ino`
- Frei konfigurierbare Variante: `relays_und_sensoren_custom.ino` (bis zu zwei MCP23017 und null bis drei Sensoren)
